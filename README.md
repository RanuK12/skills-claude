# Skills Claude

Colección de skills personalizados para agents Claude (Claude Code / Claude Desktop).

## Skills incluidos
| Skill | Descripción |
|-------|-------------|
| `daily-os-automator` | Automatización de flujos diarios en el sistema operativo |
| `deep-work-manager` | Gestión de sesiones de trabajo profundo |
| `dev-flow-optimizer` | Optimización de flujos de desarrollo |
| `linux-dev-automator` | Automatización para entornos Linux |
| `ml-architect-lab` | Laboratorio de arquitecturas ML |
| `pc-life-assistant` | Asistente de productividad personal |
| `pr-master-architect` | Generación y revisión de Pull Requests |
| `token-frugal-dev` | Desarrollo optimizado para ahorro de tokens |
| `web-research-summarizer` | Investigación web y síntesis de documentación |
| `zero-chatter` | Modo conciso sin relleno |

## Formato
Cada skill es un archivo `.skill` (empaquetado) que contiene `SKILL.md` con instrucciones, ejemplos y referencias.

## Uso
Importar los archivos `.skill` en Claude Desktop o en la configuración de Claude Code.
